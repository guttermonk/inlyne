## Instructions for Testing

1. Press **Ctrl+F** to activate search mode
2. Type any of these words: hello, world, test, apple, banana, cherry, search
3. Press **Enter** or **n** to navigate to the next match
4. Press **Shift+n** to navigate to the previous match
5. Press **Escape** to cancel search or **Ctrl+F** again to exit search mode

The search text should appear at the bottom of the window showing:
- What you're typing
- The current match number (e.g., "Search: test (1/4)")
- A colored indicator (green if matches found, orange if no matches)
